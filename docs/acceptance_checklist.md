# 受入確認チェックリスト

- 会員が年間登録を申請しても、承認前は大会申込できない。
- 管理者が振込名義・確認日を登録して入金確認し、承認すると期限が更新される。
- 却下された年間登録を会員が再申請できる。
- 会員が退会するとログインできず、管理者が有効化すると再度ログインできる。
- 最後の有効な管理者を無効化・権限解除できない。
- 下書き大会は会員画面およびAPI URLから参照できない。
- 会員CSV、大会参加者CSVを管理者だけが出力できる。
- 管理者が年度・状態・会員名・メールで年間登録レポートを絞り込み、CSVと印刷用画面を出力できる。
- 申請から7日以上の入金待ち、入金確認から3日以上の承認待ちが年間登録管理で強調表示され、ダッシュボードから各一覧へ遷移できる。
- 有効な会員アカウントだけに、年間登録期限の30日前・7日前・期限切れ後の通知がキュー経由で一度ずつ送信される。送信失敗はログに残り、他の通知は継続する。
- 年間登録の申請・再申請・入金確認・承認・却下の操作が監査ログで確認できる。
- 外部API URLは404になる。
