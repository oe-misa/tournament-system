# Requirements

## 目的

本プロジェクトは、福岡かるた会向けの会員管理・大会運営システムである。
会員はログインして大会閲覧、エントリー、成績閲覧、段位申請、年間登録更新、おみくじを利用できる。
管理者は大会管理、段位申請の承認・却下、成績入力を行える。
API は会員向けの一部主要操作を提供する。

## 背景

- 会員が大会情報や自身の状態をオンラインで確認・操作できるようにする。
- 管理者の大会運営、段位申請対応、成績入力を Web 上で行えるようにする。
- 段位、年間登録、大会エントリー、成績、おみくじを一元管理する。

## 対象ユーザー

- ゲスト
  - ランディングページや会員入口を閲覧する。
- 会員
  - ログインして会員機能を利用する。
- 管理者
  - 会員機能に加え、管理画面で運用を行う。
- API 利用者
  - `auth:sanctum` 前提で API を利用する会員。

## 機能一覧

### 1. 認証・共通

- ログイン
- 新規登録
- ログアウト
- パスワード再設定
- メール認証関連画面
- プロフィール編集
- アカウント削除

### 2. 公開ページ

- ランディングページ表示
- 会員向け案内ページ表示
- 会員入口表示

### 3. 会員ダッシュボード

- ログイン後の要約表示
- 会員の段位表示
- 年間登録期限の表示
- 本日のおみくじ結果表示
- 会員メニュー導線表示
- 管理者の場合の未処理件数表示

### 4. プロフィール

- 氏名、メールアドレスの更新
- 任意のパスワード更新
- 現在段位の確認
- 現在の年間登録期限の確認
- パスワード確認によるアカウント削除

### 5. 大会

- 大会一覧表示
- 大会詳細表示
- 大会タイトル、説明、開催日、締切、定員、最低段位条件の表示

### 6. 大会エントリー

- 会員による大会エントリー
- 年間登録期限チェック
- 段位条件チェック
- エントリー締切チェック
- 定員チェック
- 重複エントリー防止

### 7. 成績

- 会員向け成績一覧表示
- 管理者による大会ごとの成績入力
- 成績の登録・更新

### 8. 段位申請

- 会員による段位申請
- 申請時の段位一覧参照
- 申請履歴表示
- 管理者による承認
- 管理者による却下
- 管理者コメントの保存

### 9. 年間登録

- 会員による年間登録更新
- 更新可能期間のプレビュー表示
- 期限や更新可否の案内表示
- 更新履歴保存

### 10. おみくじ

- 会員による 1 日 1 回のおみくじ
- 重複実行の防止
- 結果履歴保存

### 11. 管理画面

- 管理ダッシュボード
- 大会 CRUD
- 段位申請一覧
- 段位申請の承認・却下
- 大会ごとの成績入力

### 12. API

- 自分の会員情報取得
- 大会一覧取得
- 大会詳細取得
- 大会エントリー
- 自分の成績一覧取得
- 段位申請作成

## 権限一覧

- ゲスト
  - 公開ページと認証画面の利用
- 会員
  - 大会閲覧、エントリー、成績閲覧、段位申請、年間登録更新、おみくじ
- 管理者
  - 会員機能に加え、大会管理、段位申請管理、成績入力
- API 利用者
  - `auth:sanctum` で認証した会員

## 外部連携

- 外部決済連携は未実装
- 外部通知連携は未実装
- API 認証は Sanctum を使用する

## 非機能要件

- Laravel による Web / API 実装
- 認証は Breeze ベース
- API は Sanctum ベース
- 日本語 UI / 日本語メッセージ
- 一覧系はページネーションを使用する
- 競合が起こり得る処理ではトランザクションやロックを利用する
- エラーは共通方針に従って 403 / 409 / 422 / 500 を使い分ける
- ログ出力は個人情報を出しすぎない

## 制約事項

- 年間登録は 4/1 から翌 3/31 までの年度単位で扱う
- 年間登録は会員による更新画面から実施する
- 現在有効な会員は 3/10 以降に翌年度分へ更新できる
- 期限切れ会員と新規会員は現在年度分として更新する
- 大会エントリーは年間登録期限と段位条件に依存する
- 大会定員と締切によってエントリー可否が変わる
- 段位申請は現在段位より下を申請できない
- 同日のおみくじは重複実行できない
- 管理者機能は `auth + admin` middleware で保護する

## 完成条件

- 会員がログインして主要機能を利用できる
- 管理者が大会管理、段位申請管理、成績入力を行える
- API で会員情報、大会、成績、段位申請作成が扱える
- 各業務処理でエラー条件が適切に制御される
- 現行画面と API が routes 上で到達可能である

## 確定事項

- 会員機能は Web で提供する
- 管理機能は Web で提供する
- API は会員向けの一部機能を提供する
- 大会一覧と詳細は会員が閲覧できる
- 会員は大会エントリーできる
- 会員は成績一覧を閲覧できる
- 会員は段位申請を作成し、履歴を確認できる
- 会員は年間登録更新ができる
- 会員はおみくじを 1 日 1 回引ける
- 管理者は大会 CRUD を行える
- 管理者は段位申請を承認・却下できる
- 管理者は大会成績を入力できる
- ダッシュボードは会員向け導線と管理者向け件数表示を持つ
- API は `me`、`tournaments`、`entries`、`results`、`rank-requests` を提供する

## 仮説事項

- ランディングページと会員向け案内ページは今後も導線ページとして残す
- 大会の公開状態管理は今後追加する可能性がある
- 会員キャンセル機能は今後追加する可能性がある
- 管理者向け会員管理画面は今後追加する可能性がある
- 年間登録の決済・承認フローは今後追加する可能性がある
