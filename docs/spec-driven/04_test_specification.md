# 04 Test Specification

## 完成条件

- `php artisan test` が成功する。
- `npm run build` が成功する。
- 年間登録、エントリー、段位申請の主要業務ルールが Unit/Feature テストで保証されている。
- 画面の主要導線が Feature テストで 200 または期待リダイレクトを返す。

## Unit Test

### EntryService

- 年間登録期限切れの場合、エントリーできない。
- 段位不足の場合、エントリーできない。
- 締切後の場合、エントリーできない。
- 定員到達時、エントリーできない。
- 既存エントリーがある場合、既存エントリーを返す。
- 条件を満たす場合、エントリーを作成する。
- キャンセル時、status を `cancelled` にする。

### MembershipService

- 未登録会員は現在年度末まで登録される。
- 期限切れ会員は現在年度末まで登録される。
- 当年度登録済み会員は 3/9 以前に翌年度更新できない。
- 当年度登録済み会員は 3/10 以降に翌年度更新できる。
- 翌年度登録済み会員は重複更新できない。

### RankRequestService

- 現在段位以上の申請を作成できる。
- 現在段位より下の申請を拒否する。
- 未処理申請が重複する場合、拒否する。
- 管理者は pending 申請を承認できる。
- 承認時にユーザー段位を更新する。
- 管理者以外の承認を拒否する。
- pending 以外の承認を拒否する。
- 管理者は pending 申請を却下できる。
- 管理者以外の却下を拒否する。
- pending 以外の却下を拒否する。

### RankLabel

- 段位レベルを正しいラベルへ変換する。
- 大会最低段位レベルを正しい参加条件表示へ変換する。

### Model

- 各 Model のリレーションが定義されている。
- RankRequest の表示補助メソッドが期待通り動く。

## Feature Test

### Auth

- ログイン画面を表示できる。
- 正しい認証情報でログインできる。
- 誤った認証情報でログインできない。
- ログアウトできる。
- 新規登録できる。
- パスワードリセット、メール確認、パスワード確認が Breeze 標準通り動く。

### Public

- `/` が表示され、「会員はこちら」が確認できる。
- `/mypage` が表示される。

### Member Web

- 大会一覧と大会詳細を表示できる。
- 成績一覧を表示できる。
- 段位申請作成、重複 pending 拒否、履歴表示ができる。
- 年間登録画面表示と登録処理ができる。
- 年間登録 Service 例外時にエラーを session 表示できる。
- 段位定義 JSON を取得できる。

### Entry Web

- 有効なユーザーは Web からエントリーできる。
- Service 例外時に画面へエラーを表示できる。

### Dashboard

- 会員ダッシュボードにおみくじ状態を表示できる。
- 管理者ダッシュボードに未処理件数を表示できる。

### Omikuji

- 1 日 1 回おみくじを引ける。
- 翌日は再度引ける。
- ロック競合や DB 制約競合を安全に扱う。

### Admin

- 管理者は大会を作成・更新・削除できる。
- 管理者は成績を入力・更新できる。
- 空の成績行は保存しない。
- 管理者は段位申請を承認・却下できる。
- 処理済み申請の再処理は拒否される。
- 非管理者は管理画面へアクセスできない。

### API

- 認証済みユーザーは `/api/me` を取得できる。
- 大会一覧・詳細を取得できる。
- API からエントリーできる。
- API から段位申請できる。
- Service 例外は適切な HTTP status と JSON message で返る。
